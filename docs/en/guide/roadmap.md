# Roadmap

Dev-time tool. Assets only for now. Reserved config keys warn; they are not implemented yet.

## Stages

| Stage | Status | What |
| --- | --- | --- |
| **v0.0.x** | In progress | Asset codegen; CLI (`config` / `gen`); `build_runner` (same `fast_dev` package); docs site |
| **v0.1** | Planned | Stabilize the API; more tests and examples |
| **v0.2** | Planned | Fonts generator |
| **v0.3** | Planned | Colors generator |
| **v0.4** | Planned | `fast_dev imports` |
| **Later** | Maybe | flavors, transformers |

For business-related helpers, see [Fast Package](https://github.com/ArturoYi/fast_package).
